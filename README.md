# For Anu — Final Clean Host Version

A static interactive surprise website. This final clean build keeps the existing main content, Ultimate Experience features, music, letter, proposal flow, surprise interactions, night mode, responsive styling, and reduced-motion support while removing conflicting cinematic/entry patches that could cause scroll and layout glitches.

## Run
`python3 -m http.server 8080`

Then open `http://localhost:8080/`.
