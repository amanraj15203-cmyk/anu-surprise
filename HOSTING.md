# Hosting — Anu Surprise Website

This folder is a static website. Upload the whole folder contents to any static host.

## Local test
```bash
python3 -m http.server 8080
```
Open `http://localhost:8080/`.

## Netlify
Drag the project folder into Netlify Drop, or connect the repository.

## GitHub Pages
Upload the files to a repository and enable Pages from the repository settings.

## Vercel
Import the repository as a static project; no build command is required.

Keep `music.mp3` in the same folder as `index.html`.
